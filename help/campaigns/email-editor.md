# 이메일 편집기 이해 {#email-editor}

이메일 편집기를 사용하면 캠페인 보드에서 직접 AI가 생성한 이메일을 개선할 수 있습니다. 제목 줄 및 사전 헤더를 편집하거나, 텍스트 및 이미지를 인라인으로 포맷하거나, 다른 템플릿에서 교체합니다.

캠페인 보드에서 이메일 카드를 선택하면 이메일 편집기가 사이드 패널로 열립니다. 여기에서 사용자는 제목과 프리헤더(AI가 제안하는 대체 요소 사용)를 편집하고 이메일 본문을 클릭하여 텍스트 또는 이미지를 선택하고 형식을 지정하며, AI가 생성한 변형 간을 전환하고, HTML 템플릿을 교체하고, 이메일-클라이언트 호환성을 확인하고, 테스트 이메일을 자체 받은 편지함으로 보낼 수 있습니다. 변경 사항은 자동으로 저장되고 이전 버전을 검토 및 복원할 수 있습니다.

## 액세스 방법

1. 원하는 캠페인을 열고 이메일 카드에서 편집기 열기 를 클릭합니다.

스크린샷

1. **제목** 및 **사전 머리글** 필드를 직접 편집하거나 AI에서 생성한 대체 요소 옆에 있는 **스마트 제안**&#x200B;을 클릭하세요.
1. 이메일 본문을 클릭하여 텍스트 블록 또는 이미지를 선택한 다음 나타나는 부동 도구 모음을 사용하여 텍스트 서식을 지정하거나 이미지를 관리합니다.
1. **HTML 템플릿 전환**&#x200B;을(를) 사용하여 전자 메일 본문을 다른 템플릿으로 바꾸십시오.
1. **테스트 전자 메일 보내기**&#x200B;를 사용하고 받는 사람 주소를 입력한 다음 **보내기**&#x200B;를 클릭하여 해당 주소로 실시간 미리 보기를 전자 메일로 보냅니다.
1. 버전 기록 아이콘을 사용하여 이전에 저장된 버전을 미리 보고 복원할 수 있습니다.
1. 변경 사항이 자동으로 저장됩니다. 수동 저장 단계는 필요하지 않습니다.

### 주요 동작

- 이미지 업로드는 10MB로 제한됩니다. 대략 3MB가 넘는 이미지는 자동으로 압축되며 3MB 미만의 이미지를 추천하는 품질 메모가 있습니다.
- 제목 및 프리헤더 필드에는 이 아이콘을 통해 AI가 생성한 대체 요소에 대한 옵션이 있습니다.
- Ctrl+z(Mac의 경우 CMD+z)를 사용하여 &#39;실행 취소&#39;하고 마지막 작업을 취소합니다. Ctrl+Y(Mac의 경우 CMD+y)를 사용하여 &#39;다시 실행&#39;하고 마지막 실행 취소를 되돌릴 수 있습니다. KEITH 검사 표준
- 이 아이콘을 통해 버전 기록 패널에서 저장된 이전 버전을 미리 보고 복원할 수 있습니다.
- 기본적으로 이메일당 2개의 변형이 생성됩니다. 오른쪽 썸네일을 통해 원하는 변형을 선택할 수 있습니다.

## 이 기능에서 수행할 수 없는 작업

- 드래그 앤 드롭 블록 빌더가 아닙니다. 블록 라이브러리가 없으며 콘텐츠 블록을 추가, 제거 또는 재정렬할 수 없습니다. 편집은 기존 이메일 HTML에서 직접 수행됩니다.
- 현재는 개인화/병합 태그 삽입을 지원하지 않습니다.
- 이미지에 대체 텍스트 필드를 제공하지 않습니다.
- 이메일이 &quot;준비&quot;로 간주되기 전에 제목란, 사전 헤더 또는 기타 콘텐츠 수준 검사를 시행하지 않습니다. 실행 전 검사만 이메일 콘텐츠 자체에 대한 검사가 아닌 캠페인 수준(설정 보내기, 테스트 이메일 보내기, 실제 대상자)입니다.
- 표준 캠페인 이메일 편집 보기에서는 데스크톱/모바일 미리 보기 전환을 사용할 수 없습니다. [범위를 확인하기 위해 입력이 필요합니다]
- [입력 필요 — 엔지니어와 확인하기 위해: 캠페인이 활성화/시작되면 편집기가 완전히 읽기 전용(보낸 사람 필드뿐만 아니라)이 되는지 여부]
