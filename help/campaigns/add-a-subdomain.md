# 하위 도메인 및 보낸 사람 추가 {#subdomain-senders}

하위 도메인은 브랜드나 다양한 트래픽 유형(예: 마케팅 커뮤니케이션)을 분리하는 데 사용할 수 있는 도메인의 하위 도메인입니다.

마케팅 커뮤니케이션을 전송하는 데 사용되는 &quot;mybrand.com&quot; 도메인을 사용하겠습니다. 이 경우 특정 하위 도메인을 설정할 수 있습니다.

* 잠재 고객 대상 이메일용 &quot;marketing.mybrand.com&quot; 하위 도메인

이러한 하위 도메인을 설정하면 사용 중인 도메인과 다른 하위 도메인의 평판을 유지할 수 있습니다. 예를 들어 잘못된 전달성 사례로 인해 &quot;marketing.mybrand.com&quot; 하위 도메인이 인터넷 서비스 공급자의 차단 목록에 추가되는 경우 전체 &quot;mybrand.com&quot; 도메인과 사용자가 만든 다른 하위 도메인이 추가되지 않습니다.

>[!IMPORTANT]
>
>무료 평가판의 일부로 최대 2개의 하위 도메인이 허용됩니다.

## 하위 도메인을 추가하는 방법

1. 왼쪽 탐색 메뉴에서 이름을 클릭합니다.

   스크린샷

1. **설정**&#x200B;을 클릭합니다.

   스크린샷

1. _Workspace_&#x200B;에서 **도메인 및 보낸 사람**&#x200B;을 선택합니다.

   스크린샷

1. **하위 도메인 추가**&#x200B;를 클릭합니다.

   스크린샷

1. 하위 도메인을 입력하고 **다음**&#x200B;을(를) 클릭합니다.

   스크린샷

1. DNS 공급자에 추가해야 하는 해당 값 옆에 있는 복사 아이콘 PIC를 클릭합니다.

   스크린샷

   >[!NOTE]
   >
   >DNS 공급자가 필드를 일괄 업로드할 수 있도록 허용하는 경우 **CSV 내보내기**&#x200B;를 클릭하여 모든 필드를 내보낼 수 있습니다.

1. DNS 공급자에 정보를 모두 입력했으면 동료 캠페인에서 **이러한 레코드를 추가했습니다**&#x200B;을(를) 클릭하여 계속합니다.

   스크린샷

   >[!NOTE]
   >
   >DNS 변경 사항이 전파되는 데 최대 30분이 걸릴 수 있습니다. 행에서 녹색 확인 대신 빨간색 X가 표시되면 동료 캠페인은 완료될 때까지 2분마다 확인합니다.

1. 모든 레코드의 유효성을 검사하면 창 아래쪽에 _유효성 검사 레코드_ 테이블이 나타납니다. 아래로 스크롤하여 나열된 모든 값을 복사하여 DNS 공급자에 추가합니다.

   스크린샷

1. 완료되면 동료 캠페인에서 **이 레코드를 추가함**(또는 여러 레코드가 있는 경우 **이 레코드**)을(를) 클릭하여 계속합니다.

   스크린샷

1. 보낸 사람 이름, 전자 메일 접두사, 회신 주소 이름 및 회신 주소를 입력하고 **완료 및 설정**&#x200B;을 클릭합니다.

   스크린샷

1. 새 하위 도메인이 목록에 나타납니다. 프로세스가 완료되는 데 몇 분에서 2시간까지 소요될 수 있으므로 상태: _진행 중_&#x200B;입니다.

   스크린샷

1. 프로세스가 완료되면 상태가 _확인_(으)로 변경됩니다.

   스크린샷
