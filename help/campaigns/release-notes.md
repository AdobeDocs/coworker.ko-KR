# Adobe CX Enterprise Coworker Campaigns 릴리스 정보 {#release-notes}

동료 캠페인 릴리스는 기능 배포에 대한 보다 확장 가능한 단계별 접근 방식을 고려하는 연속 제공 모델에서 작동합니다.

## 2026년 9월 {#sep-2026}

**릴리스 날짜: 2026년 9월 17일**

* Azure, GCP 또는 사용자 정의 도메인에서 호스팅되는 Databricks 작업 영역 연결
* 워크플로우가 완전히 설정될 때까지 캠페인을 더 이상 시작할 수 없습니다.
* 업데이트된 콘텐츠로 캠페인 템플릿이 새로 고쳐졌습니다.
* 연락처 목록 CSV를 업로드하는 동안 커넥터를 직접 선택하십시오.
* 긴 체험판 등록 목록을 스크롤한 후 발생할 수 있는 충돌을 해결했습니다
* 비어 있거나 중복된 헤더가 있는 대상 CSV를 업로드하면 페이지가 충돌할 수 있는 문제를 해결했습니다
* 해결된 후 채워지지 않은 상태로 표시되는 캠페인 프롬프트의 자리 표시자 텍스트가 수정되었습니다.
* 누락된 색상 그라데이션으로 인해 스킬 페이지가 충돌하는 문제를 해결했습니다
* 이미 대답한 후 동일한 질문을 반복하여 채팅이 중단되는 문제가 해결되었습니다.
* 채팅 응답에서 선택한 답변 앞에 더 이상 잘못된 ID 접두사가 표시되지 않습니다
* 이제 채팅에서 작성 상자를 채우기 위해 탭할 수 있는 빠른 다음 단계 답변을 제안합니다.
* 이제 캠페인 템플릿이 별도의 대화 상자 대신 간소화된 페이지 내 보기로 열립니다
* 이제 확장된 채팅 진행률 표시줄이 대화 내용을 보이지 않게 푸시하는 대신 내부적으로 스크롤됩니다.
* 이제 Campaign 설정이 최신 게시판 세부 정보를 보다 정확하게 반영합니다
* 이제 업그레이드 계획 대화 상자에서 보다 일관된 모양과 느낌을 사용합니다
* 깔끔한 디자인을 위해 캠페인 계획 헤더에서 중복 상태 표시기를 제거했습니다.
* 신속한 이메일 편집 내용은 이제 여러 항목이 아닌 단일 버전 기록 항목으로 함께 저장됩니다
* 초안이 생성되는 동안 브랜드 키트 제목이 가끔 누락됨
* 이미지 도구 모음에서 직접 Adobe Express을 사용하여 이미지 편집
* 이제 기본 에이전트 대상 데이터가 수동으로 새로 고치지 않고 캠페인 보드에서 동기화 상태를 유지합니다.
* 캠페인 게시판의 브랜드 로고는 각자의 공간에 맞게 더 깔끔하게 잘립니다
* 캠페인 플랜이 캠페인 보드로 이동할 때 시각적 전달 간소화

**릴리스 날짜: 2026년 9월 3일**

* 채팅 메시지를 복사하고 메시지 자체에서 바로 엄지 손가락 위로 또는 아래로 AI 응답을 평가합니다.
* 이제 캠페인이 실행되는 동안 캠페인 계획 작업 목록이 채팅 입력 위에 고정된 상태로 유지되므로 스크롤하지 않고도 진행률을 추적할 수 있습니다
* Databricks SQL Warehouse를 캠페인의 새 데이터 소스로 연결
* 이전 채팅 기반 이메일 편집기는 최신 이메일 에셋 편집기를 위해 사용이 중단되었습니다
* 이제 평가판 사용자 관리를 통해 Adobe 사용자를 제외할 수 있으므로 실제 평가판 등록을 보다 쉽게 볼 수 있습니다
* 유사한 캠페인 제안을 로드하지 못하는 문제가 해결되었습니다.
* 이제 채팅 메시지의 간격이 더 좁고 일관적입니다.

**릴리스 날짜: 2026년 9월 1일**

* 이제 큰 캠페인 이메일이 잘리지 않고 편집기에 완전히 표시됩니다
* 이제 캠페인 게시판의 시작 단추에 &quot;검토 및 실행&quot;이라는 레이블이 사용되므로 보다 명확하게 확인할 수 있습니다
* Salesforce 계정 연결에 더 이상 잘못된 Marketo 오류 메시지가 표시되지 않습니다
* 이제 Salesforce의 커넥터 목록에 자체 로고가 있습니다
* 사용 가능한 커넥터는 이제 곧 제공될 커넥터보다 먼저 나열되어 있습니다
* 이제 온보딩에 브랜드 키트가 로드되는 동안 진행 표시기가 표시됩니다.
* 이제 대상 및 지식 소스 미리 보기에는 닫기 버튼이 있으며 전체 화면을 열 수 있습니다
* 캠페인 실행이 시작된 후 캠페인 계획 카드가 더 이상 &quot;빌드 중&quot;을 표시하는 정지되지 않음
* 채팅은 더 이상 대화 기록에 임시 진행 메시지(&quot;탐색 중...&quot;)를 보관하지 않습니다.
* 이제 AI 이미지 또는 텍스트 제안 사항이 적용되는 동안 도구 모음 컨트롤이 적절하게 잠깁니다.
* 자산 편집기에서 이미지 교체가 제대로 작동하지 않는 문제를 해결했습니다

## 2026년 8월 {#aug-2026}

**릴리스 날짜: 2026년 8월 26일**

* 이제 캠페인 템플릿 카드의 아무 곳이나 클릭하면 제목뿐만 아니라 미리보기가 열립니다
* 입력을 지운 후 캠페인 프롬프트 막대 자리 표시자가 올바르게 다시 나타나며 보다 명확한 화면 판독기 지원
* 이제 &quot;프롬프트 도움말&quot; 제안이 캠페인 프롬프트 표시줄의 기존 텍스트를 올바르게 대체합니다
* 이제 구독 취소를 CSV로 다운로드하면 보고 있는 캠페인 실행만 반영됩니다
* 이제 평가판 비교에 Launch 캠페인 및 Campaign 통찰력이 포함된 기능으로 표시됩니다
* 전체 워크플로우 없이 생성된 대상자가 이제 캠페인 보드의 대상자 카드에 올바르게 표시됩니다
* 빈 상태 피드백 프롬프트는 앱 전체에서 더 자연스럽게 읽습니다.

**릴리스 날짜: 2026년 8월 25일**

* 한 브라우저 탭에서 로그인하면 다른 브라우저 탭이 자동으로 동기화되어 탭 간 계정 혼동을 해결할 수 있습니다
* 이제 빌드를 클릭하면 플랜이 가끔씩 다시 생성되지 않고 안정적으로 앞으로 이동합니다.
* 채팅의 워크플로 다이어그램은 더 많은 캔버스를 표시하므로 확대/축소 컨트롤이 더 이상 단계를 다루지 않습니다
* Campaign 세부 사항 탭의 모양이 새로워지고 일관성이 있습니다.
* 이제 도메인 및 발신자에서 전송 도메인을 저장하거나 제거하는 것이 더 빠르고 안정적입니다

**릴리스 날짜: 2026년 8월 24일**

* 생성된 캠페인 전략을 캠페인 보드에서 바로 확인할 수 있습니다
* 캠페인 유효성 검사 대화 상자에서 바로 대상자 바꾸기
* 이제 Campaign PDF 및 Word 내보내기에 실제 워크플로 다이어그램이 포함됩니다
* 인사이트 탭은 실행 직후 유용한 빈 상태로 계속 표시됩니다
* 캠페인 필드를 검토하는 동안 터치포인트 추가 또는 제거
* 캠페인 보드 도구 모음은 불필요한 버튼이 제거되어 더 간단합니다
* 도메인 및 발신자 마법사: 하위 도메인 및 안내서를 코드 마크로 검사합니다.
* 도메인 및 보낸 사람 마법사에는 입력할 때 하위 도메인 유효성 검사 오류가 인라인으로 표시됩니다.
* 증명 후 캠페인 call-to-action이 제거되어 흐름이 깔끔해졌습니다
* 이제 중국어 언어 이름이 언어 선택기에 올바르게 표시됩니다
* AI 생성 변형 썸네일이 중복 레이블 없이 안정적으로 로드됨
* 새로 만든 캠페인이 이제 홈의 최근 캠페인 목록에 바로 표시됩니다
* 이제 모든 캠페인 인사이트에 조직의 캠페인 성능에 대한 AI 생성 요약이 포함됩니다
* 워크플로 대화에 요청된 입력을 제공해도 더 이상 중단되지 않습니다
* 기존 브랜드 키트를 확인하는 동안 평가판 온보딩이 더 이상 추가 로드 화면을 깜박이지 않습니다
* 부실 샘플 대상 소스는 이제 워크플로우에서 자동으로 지워집니다.
* 이제 레이아웃, 테마 및 글꼴이 통합 Experience Cloud 셸 내에서 올바르게 렌더링됩니다.
* 유사한 캠페인 제안에는 더 이상 불필요한 채널 필드가 표시되지 않습니다

**릴리스 날짜: 2026년 8월 14일**

* 도메인 및 발신자에서 더 이상 필요하지 않은 초안 도메인 삭제
* 도메인을 설정하는 동안 각 레코드에 대한 DNS 인증 상태 확인
* 이제 도메인 세부 사항에 구성된 이메일 발신자가 표시됨
* DNS 레코드 값은 전체 텍스트에 대한 도구 설명으로 깔끔하게 잘립니다.
* 다중 선택을 사용하여 여러 이메일 텍스트 블록을 한 번에 서식 지정
* 새 캠페인을 만들 때 유사한 캠페인 제안 받기
* 캠페인 통찰력을 반복 캠페인의 단일 실행으로 범위 지정
* 프로필 메뉴에서 원하는 언어를 선택합니다
* 캠페인 템플릿 설명에 더 많은 세부 정보가 필요한 경우 대화창 흔들기
* 릴리스 노트는 탐색 및 페이지 매김을 개선하여 찾아보기가 더 쉽습니다.
* 사이드바의 최근 캠페인 목록을 접고 공간을 절약합니다.
* 이제 캠페인 인벤토리 보기가 원래 상태로 유지됩니다.
* 실행 필터 순서 변경 및 달력 선택기에서 날짜 범위로 이동
* 읽기 전용 대상 카드에서도 대상 세부 사항 미리보기
* 온보딩 시행 화면 깜박임 및 로그인 시간 문제가 해결되었습니다.
* 채팅 레일 크기 조정 핸들이 더 이상 메시지 목록 스크롤바를 차단하지 않습니다.
* 이제 브랜드 키트 만들기에 저장에 실패한 실제 이유가 표시됩니다.

**릴리스 날짜: 2026년 8월 6일**

* 이제 Campaign Insights에 옵트아웃한 의 다운로드 가능한 CSV가 있는 구독 취소가 표시됩니다
* 이메일별 성능 분류 표는 이제 인사이트 탭에 있습니다
* Insights 탭에서 직접 캠페인 여정 맵을 보십시오.
* 이제 기간 기반 대기 단계가 여정 워크플로 보기에 표시됩니다
* 가중 여정 분기는 워크플로우 편집 보기에 표시됩니다
* 이제 연락처 목록이 라이브 데이터에 연결되었습니다.
* 반복 캠페인에 &quot;인사이트 보류 중&quot; 대신 0개의 전송이 바로 표시됨
* 플레이스홀더 칩 주위에서 바로 리믹스 프롬프트 텍스트 편집
* 리믹스 편집기에서 향상된 coachmark 및 cleaner placeholder 칩
* 이제 아무 것도 실행되지 않을 때 Campaign 워크플로우 카드에 유용한 빈 상태가 표시됩니다.
* 업그레이드 계획 버튼에 더 이상 캠페인 세부 정보 헤더가 클러스터링되지 않음
* 워크플로 카드는 여정 이름과 설명이 제거된 간단한 레이아웃이 있습니다

## 2026년 7월 {#july-2026}

**릴리스 날짜: 2026년 7월 30일**

* 이제 모든 캠페인 인사이트가 개별 캠페인 인사이트 레이아웃과 새로운 일일 성과 차트와 일치합니다
* 캠페인 페이지에서 바로 라이브 캠페인 중지
* 이제 캠페인을 복제하면 새 이름만 요청됨
* 템플릿 목록에서 직접 이메일 템플릿 편집
* 실행별로 반복 캠페인 여정 보기 필터링
* 캠페인 보드에서 바로 브랜드 이미지 추가
* 이제 체험판 관리 테이블에서 이메일 검색, 페이지 매김 및 전체 CSV 내보내기 지원
* &quot;Surprise me&quot; 버튼은 이제 애니메이션 지연 없이 즉시 응답합니다
* 이 기능을 다시 작업하는 동안 캠페인 이메일 구독 취소 설정을 제거했습니다.
* 이미 설정된 캠페인 일정을 다시 시작하지 않고 편집합니다.
* 더 빠른 액세스를 위해 오버플로 메뉴에서 쓰기 스타일 편집기를 엽니다.
* 이제 Enter 키를 누르면 앱의 모든 프롬프트 모음에서 일관되게 제출됩니다.

**릴리스 날짜: 2026년 7월 23일**

* 캠페인을 즉시, 선택한 시간에 한 번 또는 반복적으로 전송하도록 예약합니다.
