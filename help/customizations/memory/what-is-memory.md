# [!DNL Coworker] 메모리: 보다 생산적인 워크플로를 위해 AI 개인화

[!DNL Coworker] 메모리는 작업에 가장 중요한 환경 설정, 수정 사항 및 작업 스타일을 기억하여 보다 일관되고 효율적이며 개인화된 상호 작용을 만드는 데 도움이 됩니다.

새로운 대화를 시작할 때마다 동일한 지침을 반복하는 대신, 메모리를 사용하면 동료가 선택한 정보를 세션 간에 전달할 수 있으므로 보다 빠르고 관련성 있는 응답을 제공할 수 있습니다.

>[!VIDEO](https://video.tv.adobe.com/v/3503671/?captions=kor&learn=on&enablevpops)

## 메모리 이해

기억은 대화 전반에 걸쳐 다음과 같은 유용한 정보를 유지하도록 설계되었습니다.

- 기본 응답 형식
- 작업 스타일 및 커뮤니케이션 환경 설정
- 비즈니스 용어
- 전문 컨텍스트
- 보고 기본값 및 분석 환경 설정
- 시간대 설정

예를 들어, 일관되게 간결한 글머리 기호 응답을 선호하거나 비즈니스 객체에 특정 용어를 사용하는 경우, 동료는 이러한 환경 설정을 기억하고 향후 대화에서 자동으로 적용할 수 있습니다.

## 메모리와 대화 기록 비교

기억과 대화 기록은 서로 다른 목적에 쓰인다.

### 대화 기록

대화 기록을 통해 다음과 같은 작업을 수행할 수 있습니다.

- 이전 채팅으로 돌아가기
- 이전 토론 검토
- 과거 상호 작용 참조

### 메모리

Coworker는 메모리를 사용하여 다음을 수행할 수 있습니다.

- 선택한 환경 설정 유지
- 저장된 수정 사항 적용
- 향후 상호 작용 개인화
- 세션 간 일관성 향상

기억은 개인화 계층이지 모든 대화의 기록이 아니다.

## 메모리와 비즈니스 컨텍스트 비교

메모리는 비즈니스 컨텍스트와 혼동하면 안 됩니다.

### 비즈니스 컨텍스트

비즈니스 컨텍스트 근거 다음과 같은 조직 정보의 동료:

- 회사 데이터
- 정책
- 거버넌스 프레임워크
- 연결된 엔터프라이즈 시스템

### 메모리

메모리는 개별 사용자와 해당 사용자의 선호도에 중점을 둡니다.

이는 상호 작용을 개인화하는 데 도움이 되지만 조직의 데이터 소스, 권한 또는 거버넌스 컨트롤을 대체하지는 않습니다.

## 메모리에 기본 설정 저장

정보를 저장하는 가장 쉬운 방법 중 하나는 대화 중에 이를 명확하게 진술하는 것이다.

해당 예는 다음과 같습니다.

- 전문적인 역할 및 책임
- 기본 커뮤니케이션 스타일
- 보고 환경 설정
- 시간대 정보
- 자주 사용되는 용어

&quot;기억...&quot;과 같은 구문 사용 동료는 이후 세션을 위해 유지해야 하는 환경 설정을 식별할 수 있습니다.

## 실제 예: Campaign 성과 보고

이 비디오에서는 메모리가 Customer Journey Analytics을 사용하여 보고 워크플로를 간소화하는 방법을 보여 줍니다.

이 예제에서는

1. 사용자가 캠페인 성과 보고서를 요청합니다.
2. Coworker는 데이터 소스 및 보고 구성 요소를 식별합니다.
3. 사용자가 기본 보고 설정을 메모리에 저장합니다.
4. 동료 는 향후 분석에서 이러한 환경 설정을 자동으로 적용합니다.

따라서 후속 보고서는 추가 지침 없이 사용자가 선호하는 차원, 지표 및 보고 가정을 사용하여 전달됩니다.

## 메모리 관리

사용자는 메모리에 저장된 정보를 계속 제어할 수 있습니다.

**사용자 지정 > 메모리**&#x200B;에서 사용자는 다음을 수행할 수 있습니다.

- 메모리 활성화 또는 비활성화
- 저장된 환경 설정 검토
- 개별 메모리 항목 검사
- 저장된 정보 편집
- 더 이상 유용하지 않은 메모리 삭제

사용 가능한 컨트롤은 조직 설정 및 관리자가 활성화한 Adobe 환경에 따라 달라질 수 있습니다.

## 중요한 고려 사항

메모리는 기록 시스템이 아닌 개인화를 위해 설계되었습니다.

메모리를 다음에 대한 신뢰할 수 있는 소스로 사용하지 마십시오.

- 고객 데이터
- 캠페인 성과 데이터
- 법적 요구 사항
- 규정 준수 결정
- 보안 결정

메모리는 다음과 같지 않습니다.

- Adobe 제품에 대한 액세스 권한 부여
- 추가 권한 제공
- 거버넌스 제어 재정의
- 조직 데이터 시스템 교체

항상 조직의 거버넌스 정책 및 관리자 지침을 따르십시오.

## 주요 학습 사항

Adobe 동료의 메모리는 대화 간에 중요한 환경 설정과 수정 사항을 전달하여 반복적인 지침을 줄이고 보다 개인화된 AI 경험을 만들 수 있도록 지원합니다.

Coworker는 사용자의 작업 방식을 기억하여 조직에서 설정한 거버넌스 및 보안 제어 내에서 계속 작업하는 동안 시간이 지남에 따라 점점 더 많은 도움이 될 수 있습니다.
