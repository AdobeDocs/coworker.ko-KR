# 동료 플러그인: 구성 요소, 작동 방법 및 설치 방법

이 비디오에서는 플러그인을 소개하고 새로운 기능으로 [!DNL Coworker]을(를) 확장하는 방법을 설명합니다. 플러그인의 정의, 구성 요소, 플러그인이 스킬 및 MCP 서버와 관련되는 방법, 작업 영역에서 플러그인을 설치, 사용 및 제거하는 방법에 대해 알아봅니다.

>[!VIDEO](https://video.tv.adobe.com/v/3503656/?learn=on&enablevpops)

## 플러그인이란?

플러그인은 Adobe Coworker의 관련 기능을 설치할 수 있는 패키지입니다. 특정 비즈니스 기능 또는 사용 사례를 위해 설계된 사용 준비 도구키트로 생각해 보십시오.

플러그인에는 다음이 포함될 수 있습니다.

- 특정 작업을 수행하는 전문 기술
- 외부 Adobe 솔루션 및 서비스에 Coworker를 연결하는 MCP 서버
- 배포 및 관리를 간소화하는 번들 기능

## 주요 개념 이해

이 비디오에서는 몇 가지 중요한 구성 요소 간의 관계를 설명합니다.

| 구성 요소 | 용도 |
|-----------|---------|
| 마켓플레이스 | 사용 가능한 플러그인이 검색되는 카탈로그 |
| 플러그인 | 설치 가능한 기능 패키지 |
| 기술 | 특정 작업을 수행하는 재사용 가능한 지침 |
| MCP 서버 | 외부 도구 및 서비스에 대한 연결 관리 |

연결된 Adobe 솔루션의 예는 다음과 같습니다.

- Adobe Journey Optimizer
- Real-Time CDP
- Adobe Target
- Adobe Workfront

## 설치된 플러그인 보기

다음을 수행하는 방법을 알아보세요.

1. **사용자 지정** 열기
2. **Plugins**(으)로 이동
3. 설치된 플러그인 패키지 검토
4. 플러그인 소스 정보 및 설명 보기
5. 플러그인 세부 정보 및 기능 살펴보기

이 비디오에서는 구성, 권한 및 활성화된 기능에 따라 조직 간에 플러그인 가용성이 다를 수 있는 이유도 설명합니다.

## 플러그인 기능 살펴보기

플러그인에 다음과 같은 일반적인 운영 작업을 완료하는 데 도움이 되는 많은 기술 컬렉션이 포함될 수 있는 방법을 확인하십시오.

- 중복 대상 찾기
- Experience Platform 데이터 흐름 상태 모니터링
- 고객 데이터 분석
- 여정 생성 및 최적화 지원

## 새 플러그인 설치

이 연습에서는 다음 방법을 보여 줍니다.

1. 사용 가능한 마켓플레이스 찾아보기
2. 플러그인 찾기
3. 플러그인 세부 사항 검토
4. 플러그인 설치
5. Coworker에서 새로운 기능 사용 가능

## 동료에서 플러그인 사용

설치 후 이 비디오에서는 채팅 환경에서 플러그인을 사용하는 방법을 보여 줍니다.

이 예에서는 구매 후 멤버에게 포인트를 지급하는 충성도 문제를 생성하는 방법을 보여 줍니다.

실행 중에 Coworker는 다음을 투명도로 제공합니다.

- 사용 중인 스킬
- 데이터 소스 참조
- 실행된 쿼리
- 결과 생성 방법

## 거버넌스와 보안

주요 개선 사항은 플러그인을 설치해도 조직의 거버넌스 제어가 무시되지 않는다는 것입니다.

동료는 계속해서 다음을 수행합니다.

- 사용자 권한
- 액세스 제어
- 승인 요구 사항
- Adobe 조직 거버넌스 정책

플러그인을 설치해도 사용자가 사용할 권한이 아직 없는 제품 또는 작업에 대한 액세스 권한은 자동으로 부여되지 않습니다.

## 플러그인 제거

이 비디오는 더 이상 필요하지 않은 경우 설치된 플러그인을 제거하는 방법을 보여 주는 것으로 마무리됩니다.

플러그인을 제거하면 해당 패키지 내에 번들로 제공된 기능도 제거됩니다.

## 주요 테이크아웃

플러그인을 사용하면 관련 기술을 패키징하고 설치 가능한 솔루션에 대한 연결을 관리하여 Coworker를 확장할 수 있습니다. 마켓플레이스는 사용자가 플러그인을 찾고, 기술이 특정 작업을 수행하고, MCP 서버가 Coworker를 안전하고 통제된 방식으로 Adobe Experience Cloud 애플리케이션 및 서비스에 연결할 수 있도록 지원합니다.
