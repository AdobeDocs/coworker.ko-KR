# [제품]의 CX Enterprise Coworker

Coworker는 Adobe의 대화형 AI로 [제품]과 같은 CX Enterprise 애플리케이션과 긴밀하게 통합됩니다. 작업을 빠르고 올바르게 수행하기 위한 Adobe 모범 사례에 대해 교육되므로 여러 화면과 도구를 클릭하지 않고 &quot;[예제 프롬프트 1]&quot; 또는 &quot;[예제 프롬프트 2]&quot; 등의 일반 언어로 원하는 작업을 설명하고 Coworker가 작업을 계획하고 연결된 Adobe 애플리케이션에서 실행하며 검토 결과를 보여 줍니다.

[Product]의 경우, 이는 [제품에서 수동 작업을 수행하는 데 걸리는 시간이 ]보다 짧고 Coworker가 생성하는 항목을 검토하고 승인하는 데 걸리는 시간이 더 많다는 것을 의미합니다. 동료가 계획, 실행 및 후속 작업을 처리하는 동안 모든 단계에서 제어권을 유지합니다.
