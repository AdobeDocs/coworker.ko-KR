# CX Enterprise Coworker을 사용하여 아이디어부터 활성화 준비 대상까지

Coworker를 사용하여 일반 언어 요청을 타겟팅된 마케팅 대상자로 변환하는 방법을 알아봅니다. 명확한 질문에 답변하여 대상자를 세분화한 다음 Coworker로 하여금 플랫폼에서 직접 대상자를 만들어 여러 대상을 활성화할 수 있도록 하십시오.
