# Coworker, AEM 및 CJA을 통해 데이터 통찰력 향상

Adobe CX Enterprise Coworker이 데이터 인사이트 목표를 Adobe Experience Manager(AEM), Adobe Experience Platform(AEP), Web SDK 및 Customer Journey Analytics(CJA)에서 연결된 구현 워크플로우로 변환하는 데 어떻게 도움이 되는지에 대해 알아봅니다. Coworker가 구현을 계획하고, 지원되는 작업을 실행하고, 제품 및 개발 단계를 안내하고, CJA에서 WKND 웹 사이트 참여 데이터를 분석할 수 있을 때까지 워크플로우 전반에서 컨텍스트를 유지하는 데 어떻게 도움이 되는지 확인하십시오.
