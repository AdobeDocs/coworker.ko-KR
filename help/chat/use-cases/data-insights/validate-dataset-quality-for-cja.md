# [!DNL Coworker]의 데이터 유효성 검사 스킬로 Customer Journey Analytics 데이터의 유효성 검사

데이터 품질은 Adobe Customer Journey Analytics(CJA)에서 정확한 보고를 하는 기반입니다. 지표, 대시보드, 세그먼트 또는 고객 여정을 작성하기 전에 기본 Adobe Experience Platform(AEP) 데이터를 신뢰할 수 있는지 여부를 이해하는 것이 중요합니다.

이 비디오에서는 쿼리를 작성하거나 수동으로 데이터를 검사하지 않고도 **Coworker의 데이터 유효성 검사 기술**&#x200B;을 사용하여 Customer Journey Analytics 구현을 지원하는 데이터 세트의 품질을 빠르게 평가하는 방법에 대해 알아봅니다.

>[!VIDEO](https://video.tv.adobe.com/v/3503519/?learn=on&enablevpops)

## CJA 보고 이면의 데이터 세트 살펴보기

동료가 식별할 수 있는 방법:

- Customer Journey Analytics에 연결된 데이터 세트
- 특정 샌드박스와 연결된 연결 및 데이터 보기
- 보고를 적극적으로 지원하는 데이터 세트
- 스트리밍 상태 및 ID 네임스페이스와 같은 주요 데이터 세트 특성

보고서를 제공하는 데이터 세트를 정확히 이해하면 가장 중요한 위치에 유효성 검사 작업에 집중할 수 있습니다.

## 데이터 세트 스키마 및 사용 가능한 필드 탐색

Adobe Experience Platform에서 직접 데이터 세트 스키마를 검사하는 방법을 알아봅니다.

Coworker는 스키마 세부 정보 및 표면을 검색합니다.

- Commerce 및 거래 필드
- 제품 정보
- 웹 인터랙션 데이터
- ID 필드
- 캠페인 및 마케팅 속성
- 장치 및 지역 차원

이렇게 하면 분석에 사용할 수 있는 필드 인벤토리가 제공되며 스키마에 있는 필드와 사용 가능한 데이터가 포함된 필드 간의 차이점이 강조 표시됩니다.

## ID 품질 확인

ID 데이터는 개인 수준 보고 및 크로스 채널 여정 분석을 지원하기 때문에 Customer Journey Analytics에 필수적입니다.

이 비디오에서는 Coworker가

- ID 필드 유효성 검사
- Null 값 및 데이터 완전성을 확인합니다.
- 식별자 품질 평가
- 표면에 ID 속성이 없거나 사용할 수 없습니다.

예제 유효성 검사는 ECID 및 이메일 ID가 완전히 채워져 샘플에서 유효하지만 Analytics ID를 검색할 수 없음을 보여 줍니다. 프로필 결합 및 보고를 지원할 수 있는 식별자를 결정할 때 유용한 신호를 제공합니다.

## 개별 필드 품질 분석

데이터 세트에 필드가 있을 수 있지만 보고에 적합하지 않습니다.

Coworker가 캠페인 추적 필드 및 보고서를 확인하는 방법을 확인합니다.

- 인구 비율
- Null 백분율
- 데이터 일관성
- 잘못된 값 감지

이 예제에서 표시되는 추적 코드 값은 깔끔하고 일관되지만 행의 약 85%가 null입니다. 이렇게 하면 CJA 차원 또는 캠페인 지표가 필드에 빌드되기 전의 주요 보고 사각지대가 표시됩니다.

## AI 기반 데이터 세트 유효성 검사 수행

Coworker는 개별 필드를 한 번에 하나씩 확인하는 대신 전체 데이터 세트를 평가할 수 있습니다.

데이터 유효성 검사 기술에 대해 알아봅니다.

- 유효성 검사에 중요한 필드 선택
- 완성도 및 품질 평가
- 필드 간 데이터 상태 비교
- 강점과 잠재적인 보고 위험 강조

유효성 검사 결과는 CJA에 대한 실행 가능성 맵을 제공합니다. 웹 페이지 이름 및 이메일 코드와 같은 클린 필드는 보고할 준비가 될 수 있지만, 구매 값, 캠페인 이름 및 추적 코드와 같은 스파스 필드는 조사가 필요합니다.

## 매출 및 기여도 위험 파악

또한 이 비디오에서는 데이터 유효성 검사가 다음을 포함하여 보고 정확성에 영향을 주는 문제를 찾는 방법을 보여 줍니다.

- 스파스 캠페인 데이터
- 속성 정보 누락
- 불완전한 트랜잭션 값
- 매출 측정 차이

표시된 데이터 세트에서 구매 카운트는 사용할 수 있지만 주문 금액은 안정적으로 채워지지 않습니다. 이는 매출 보고를 신뢰하기 전에 조사해야 할 문제이다.

## Customer Journey Analytics에 데이터 유효성 검사가 중요한 이유

Customer Journey Analytics은 그 뒤의 데이터만큼 신뢰할 수 있을 뿐입니다.

보고서를 작성하기 전에 데이터 세트의 유효성을 검사하면 팀이 다음과 같은 작업을 수행할 수 있습니다.

- 분석 결과에 대한 신뢰도 향상
- 데이터 거버넌스 관행 개선
- 보고 오류 감소
- 이전에 구현 문제 식별
- 예기치 않은 지표의 문제를 보다 효율적으로 해결

Coworker를 사용하면 자연어 프롬프트를 사용하여 이러한 검사를 시작할 수 있으므로 기술 사용자와 비기술 사용자가 데이터 유효성 검사에 보다 쉽게 액세스할 수 있습니다.
