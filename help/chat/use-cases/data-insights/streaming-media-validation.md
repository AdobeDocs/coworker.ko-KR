# Coworker를 사용하여 Streaming Media 구현 확인

Adobe CX Enterprise Coworker에는 Edge Network에서 Adobe 스트리밍 미디어(비디오 및 오디오 Analytics) 구현을 확인하여 Customer Journey Analytics 및/또는 Adobe Analytics에 제공하는 스트리밍 미디어 유효성 검사 기술이 포함되어 있습니다. Assurance, 데이터 세트 구성, XDM 스키마 필드 그룹, Customer Journey Analytics 데이터 보기 설정 및 원시 네트워크 로그를 수동으로 상호 참조하는 대신 단일 유효성 검사 보고서를 받게 됩니다.

Streaming Media 추적을 구현하거나 문제를 해결하는 경우 이 기술을 사용하여 구현이 올바르게 구성되었는지 확인하고, 예상대로 데이터를 수집하고, 추적하려는 내용을 단일 동료 채팅 대화 내에서 모두 캡처할 수 있습니다.

>[!NOTE]
>
>다음 사항을 고려하십시오.
>
>* 이 스킬은 사용자 지정 구현 또는 업그레이드 단계([Coworker로 구현 계획](./implementation-guide.md) 참조), 구현([Coworker 프로젝트로 구현 체크리스트 생성](./intelligent-checklist.md) 참조) 및 유효성 검사(이 스킬)와 같은 대규모 선택적 워크플로의 일부입니다. 세 단계를 모두 사용할 필요는 없습니다. 예를 들어 계획이나 체크리스트를 생성하지 않고 스트리밍 미디어 구현의 유효성을 검사할 수 있습니다.
>* 이 스킬은 문제를 확인 및 진단합니다. 구성 또는 데이터를 수정하지 않습니다. 결과를 사용하여 자체 수정 사항을 안내합니다.

이 스킬을 사용하여 다음을 수행합니다.

* 데이터 스트림, XDM 스키마, 데이터 세트 및 Customer Journey Analytics 데이터 보기에서 구성 감사를 실행합니다. 첫 번째 끊어진 체크포인트가 가능한 원인으로 플래그가 지정됩니다.

  이 기능은 현재 제한된 가용성입니다.

* 특정 비디오 세션 ID의 유효성을 검사하고 불일치가 발생한 홉, 데이터 세트 수집 또는 Customer Journey Analytics 매핑을 정확하게 확인하십시오.

* 라이브 Assurance 세션이 없어도 업로드된 Charles 또는 HAR 로그 또는 더 간단한 URL 목록에서 세션을 확인할 수 있습니다.

  이 기능은 현재 제한된 가용성입니다.

* 구성 및 최근 세션 샘플을 롤업하는 세션 ID 또는 로그가 필요하지 않은 단일 프롬프트로 전체 상태 검사를 받습니다.

## 시작하기에 앞서

<!-- FLAG: General access prerequisite is inferred, not stated explicitly in source docs. Per-mode inputs (session ID, log file) are directly sourced from Functional Requirements. -->

### 필요한 정보

스트리밍 미디어 구현의 유효성을 검사하려면 다음이 필요합니다.

* 조직의 Adobe Experience Platform 및 Customer Journey Analytics 데이터가 연결된 동료에 대한 액세스 권한.

* 세션 ID 유효성 검사의 경우 확인할 비디오 세션 ID입니다.

* 로그 기반 유효성 검사의 경우, Charles 또는 HAR 로그 파일 또는 .txt, .md 또는 .json 형식의 더 간단한 URL 목록입니다.

구성 감사 또는 전체 상태 검사에 특정 입력이 필요하지 않습니다. 동료는 기존 구성을 읽고 최근 세션을 자동으로 샘플링합니다.

### 제한 사항

이 스킬을 사용하기 전에 다음 사항에 유의하십시오.

* **진단만**: 이 스킬은 구성 또는 데이터를 수정하지 않습니다. 이는 문제를 식별하며 사용자가 변경합니다.
* **스트리밍 미디어만**: 이 스킬은 Edge Network의 스트리밍 미디어 구현을 다룹니다. 비미디어 데이터 세트와 표준 웹 또는 앱 Analytics 구현은 다른 Coworker 유효성 검사 기술에서 다룹니다.
* **온디맨드 전용**: 이 스킬은 실시간 또는 연속 모니터링을 제공하지 않습니다. 진행 중인 경고가 아닌 확인을 원할 때 실행합니다.
* **기본 제공 웹 크롤러 없음**: 이 스킬은 사용자의 사이트 또는 앱을 크롤링하지 않습니다. 크롤링을 헤드드리스로 확인하려면 웹 크롤러 또는 브라우저 출력을 증거로 제공하십시오.
* **Edge Network 구현만**: 기존 Media SDK 및 Analytics 전용 구현 경로는 지원되지 않습니다.
* **더 광범위한 기능이 아직 포함되지 않았습니다**: 라이브 이벤트 및 하트비트 스트림 유효성 검사, 고객 플레이북 또는 시나리오 유효성 검사, 다중 플랫폼 기록 대시보드 롤업 및 다운스트림 Real-Time CDP 또는 Adobe Journey Optimizer 활성화 유효성 검사가 이후 릴리스에 예정되어 있습니다.

## 유효성 검사 세션 시작

1. 동료에게 로그인합니다.

1. [!UICONTROL **새 채팅**]&#x200B;을 선택하세요.

1. 텍스트 필드에서 검증할 내용을 설명합니다. 예:

   **프롬프트**

   > 비디오 세션 ID의 유효성을 #123.

   요청이 스트리밍 미디어 유효성 검사 스킬로 라우팅되며, 이 스킬은 일치하는 유효성 검사 모드를 실행합니다.

1. (조건부) 스킬에 세션 ID 또는 로그 파일과 같은 추가 정보가 필요한 경우 요청이 있으면 제공합니다.

## 유효성 검사 모드 선택

스트리밍 미디어 유효성 검사 스킬에는 네 가지 모드가 포함됩니다.

### 구성 감사

이 기능은 현재 제한된 가용성입니다.

XDM 스키마, 데이터 세트 및 데이터 준비 규칙 또는 Customer Journey Analytics 파생 필드를 포함하여 데이터스트림에서 Customer Journey Analytics 데이터 보기까지의 전체 Adobe Experience Platform 흐름을 확인합니다. 동료는 홉당 통과/실패 스코어카드를 보고하고 가능한 원인으로 첫 번째 끊어진 체크포인트에 플래그를 지정합니다.

프롬프트 예:

* 데이터 보기, 데이터 세트 및 데이터 스트림에 대한 스트리밍 미디어 구성을 확인합니다.
* 내 스트리밍 미디어 구성을 끝까지 확인합니다.
* Media Analytics 데이터 스트림이 Customer Journey Analytics에 대해 올바르게 설정되었습니까?

### 세션 ID 유효성 검사

특정 비디오 세션에 대한 Adobe Experience Platform 데이터 보기에 대해 Customer Journey Analytics 데이터 세트 행을 교차 확인하고 간격이 데이터 세트 수집 문제인지 아니면 Customer Journey Analytics 매핑 문제인지를 확인합니다.

프롬프트 예:

* 비디오 세션 ID의 유효성을 #123.
* 세션 abc-123이 Customer Journey Analytics에 표시되지 않는 이유는 무엇입니까?
* 데이터 세트와 Customer Journey Analytics 데이터 보기 간에 세션 xyz를 비교합니다.

### 로그 기반 유효성 검사

이 기능은 현재 제한된 가용성입니다.

라이브 Assurance 세션이 필요 없이 업로드한 Charles 또는 HAR 로그 또는 더 간단한 URL 목록에서 세션을 확인합니다. 동료는 엔드포인트 패턴, 응답 코드, 이벤트 시퀀싱 및 ping 케이던스를 확인하고, 검사가 완전 신뢰 시 실행되었거나, 신뢰도가 저하되었거나, 건너뛴 상태를 확인합니다.

프롬프트 예:

* 스트리밍 미디어 데이터의 첨부된 로그를 확인합니다.
* 이 Charles 로그에서 세션 ID를 #456.
* 예상 미디어 Ping에 대해 이 URL 목록의 유효성을 검사합니다.

### 유효성 검사 대시보드

단일 프롬프트로 전체 상태 검사를 받습니다. Coworker는 구성 감사와 간단한 샘플 세션 검사를 하나의 상태로 롤업하고 로그가 제공되지 않은 경우 로그 기반 검사가 실행되지 않았다고 명시적으로 설명합니다.

프롬프트 예:

* 스트리밍 미디어 데이터를 확인합니다.
* 내 스트리밍 미디어 구현에 대한 보고서를 제공합니다.
* 스트리밍 미디어 구현은 전반적으로 얼마나 건전합니까?

## 결과 검토

각 모드는 유효성 검사에 적합한 형식으로 결과를 반환합니다.

**구성 감사 결과**

데이터스트림, XDM 스키마, 데이터 세트, Customer Journey Analytics 데이터 보기, 데이터 준비 또는 파생된 필드 규칙을 다루는 홉당 통과/실패 스코어카드입니다. 동료는 첫 번째 실패 홉을 가능한 근본 원인으로 식별합니다.

**세션 ID 유효성 검사 결과**

세션 ID, 컨텐츠 메타데이터, 이벤트 유형별 행 수, 주요 지표 값 및 무결성 메모를 포함하여 Customer Journey Analytics 전용 보고 요약입니다. 공백이 있는 경우 동료는 데이터 세트 수집 또는 Customer Journey Analytics 매핑 단계에서 공백이 발생했는지 여부를 식별합니다.

>[!NOTE]
>
>세션 ID 및 인증된 ID 값은 기본적으로 내보내기 또는 공유 요약에서 제외됩니다.

**로그 기반 유효성 검사 결과**

엔드포인트 패턴, 응답 코드, 이벤트 순서 및 ping 케이던스를 다루는 업로드된 로그의 구조적 및 시퀀스 유효성 검사. 전체 로그 캡처를 제공했는지 또는 더 간단한 URL 목록을 제공했는지 여부에 따라 검사가 완전 신뢰로 실행되었고, 신뢰도가 저하되었을 때 실행되었으며, 건너뛴 동료 상태입니다.

**대시보드 결과**

구성 감사 결과를 최근 세션에 대한 샘플 검사와 결합하여 &quot;구성 + 사용 가능한 데이터&quot;라는 레이블이 지정된 단일 통합 상태. 샘플링한 세션을 동료명으로 지정하며, 제공된 로그가 없기 때문에 로그 기반 검사가 실행되지 않았다고 명시적으로 설명합니다.

## 유효성 검사 작동 방식

각 모드는 전용 엔진에 매핑됩니다.

* **구성 유효성 검사 엔진**: 데이터 스트림, XDM 스키마, 데이터 집합 및 Customer Journey Analytics 데이터 보기 구성을 읽고 고정 체크포인트 집합에 대해 평가합니다.
* **세션 상호 검사 엔진**: 세션 ID가 주어지면 데이터 집합과 Customer Journey Analytics 데이터 보기를 쿼리하고 해당 세션에 대한 예상 행 수와 유형을 계산하고 각 홉에서 실제 결과를 비교합니다.
* **로그 구문 분석기 및 유효성 검사기**: 업로드한 로그 또는 URL 목록을 구문 분석하고, 요청 시퀀스 및 타이밍을 다시 구성하고, 구조적, 시퀀싱 및 네트워크 레이어 검사를 적용합니다.
* **대시보드 집계 엔진**: 구성 유효성 검사 엔진 및 세션 상호 검사 엔진의 샘플 실행을 실행하고 세션 ID, 로그 또는 플레이북을 제공하지 않은 경우 단일 상태로 결합합니다.
