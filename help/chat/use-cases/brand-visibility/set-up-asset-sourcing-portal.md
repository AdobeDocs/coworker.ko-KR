# 동료 채팅을 사용하여 자산 소싱 포털 구축

Coworker를 사용하여 AEM Assets에 대한 Adobe Asset 소싱 포털을 구성하고 공급자에게 범위 지정 포털 액세스 권한을 제공하는 방법에 대해 알아봅니다. Adobe Experience Manager Assets의 사용자 지정 메타데이터 필드를 매핑하고 자산을 수집할 때 메타데이터를 자동으로 동기화합니다.
